## 3. Part II: Hero Video Performance Re-Engineering (Altura Architecture Port)

### A. Context & User Request
The user requested:
> *"also for the hero section video of https://maison-dvue.vercel.app/ , i want the tech to work like , how i have done it for my altura website https://altura-indol.vercel.app/ , you can check it on github , can u implement the same tech here as well https://maison-dvue.vercel.app/"*

### B. Architectural Diagnosis: Maison d'Vue Canvas vs. Altura In-Memory Video

| Metric / Feature | Old Maison d'Vue Engine | Altura Architecture Port (New) |
|---|---|---|
| **Technology** | Canvas 2D frame-by-frame draw (`MdvHeroCanvasEngine`) | Native `<video>` element scrubbed via scroll (`MdvHeroVideoEngine`) |
| **Network Requests** | **300 separate image requests** (`frame_0001.webp` to `frame_0300.webp`) | **1 single MP4 video file** pre-fetched in `<head>` |
| **Download Size** | **~29 MB** for image frames | **9.05 MB** (Desktop 1080p) / **2.40 MB** (Mobile) |
| **Memory Buffer** | Array of 300 `HTMLImageElement` objects | In-memory `Blob` (`URL.createObjectURL(blob)`) |
| **Scrub Performance** | Heavy JS main-thread decode & 2D canvas draw | Hardware-accelerated GPU video decode |
| **Downstream Impact** | Saturated network connection, delaying downstream video playback | Clean pipe: other page videos load and start instantly |

### C. Technical Implementation Steps

#### 1. Video Encoding with GOP & Scrub Optimization
Using `ffmpeg`, the 300 high-resolution frames were encoded into two specialized H.264 MP4 streams designed for fast random-access seeking:
* **Desktop:** `assets/hero-scroll-desktop.mp4` (9.05 MB)
  * Resolution: 1080p progressive, 24 fps
  * Bitrate optimization: `-crf 25`, `-preset slow`
  * Scrubbing flags: `-g 12` (short GOP keyframe interval every 0.5s), `-tune fastdecode`, `-movflags +faststart`
* **Mobile:** `assets/hero-scroll-mobile.mp4` (2.40 MB)
  * Optimized bitrate: `-crf 24`, `-level 3.1`, `-g 12`

#### 2. Early In-Memory `<head>` Prefetch
Added a script directly in `<head>` before stylesheets and DOM body parse:
```html
<script>
/* Altura In-Memory Hero Film Architecture:
   The hero is scrubbed, not played: every scroll tick seeks. Streamed from a CDN, each seek into a part that has not
   arrived yet cancels and restarts a request, causing video stalls. Fetch the whole file once into memory right now,
   and scrub seamlessly from that in-memory Blob copy at 60fps. window.__hero is read by the main hero engine. */
(function(){
  try{
    if(matchMedia("(prefers-reduced-motion: reduce)").matches||!window.fetch||!window.URL||!window.Blob)return;
    var isMob = matchMedia("(max-width: 767px)").matches;
    var h = window.__hero = {
      file: isMob ? "assets/hero-scroll-mobile.mp4" : "assets/hero-scroll-desktop.mp4",
      loaded: 0,
      total: 0,
      url: null,
      done: false,
      failed: false,
      fn: null,
      ctl: null
    };
    var fin = function(){ if(h.fn) h.fn(); };
    h.ctl = window.AbortController ? new AbortController() : null;
    fetch(h.file, h.ctl ? { signal: h.ctl.signal } : {}).then(function(r){
      if(!r.ok) throw 0;
      h.total = +r.headers.get("content-length") || (isMob ? 2500000 : 9500000);
      if(!r.body || !r.body.getReader) return r.blob();
      var rd = r.body.getReader(), parts = [];
      return (function pump(){
        return rd.read().then(function(x){
          if(x.done) return new Blob(parts, { type: "video/mp4" });
          parts.push(x.value);
          h.loaded += x.value.length;
          return pump();
        });
      })();
    }).then(function(b){
      h.url = URL.createObjectURL(b);
      h.done = true;
      fin();
    }).catch(function(){
      h.failed = true;
      fin();
    });
  }catch(e){}
})();
</script>
```

#### 4. The `MdvHeroVideoEngine` Controller
Replaced the previous 540-line `MdvHeroCanvasEngine` with `MdvHeroVideoEngine`:
* **iOS / Mobile Priming:** Automatically calls `video.play()` muted and immediately holds it upon the `playing` event to grant iOS Safari programmatic seek permissions.
* **Streaming Bridge:** If the user scrolls before the in-memory blob has finished downloading, the engine attaches `video.src = hero.file` immediately, so seeking works without hesitation, then hot-swaps to `video.src = hero.url` when ready.
* **Frame Throttling:** Seeks only when `Math.abs(target - shown) >= 1 / 48` (half a frame at 24fps) to eliminate redundant decode cycles.
* **Lenis Smooth Scroll:** Smooth scroll momentum from Lenis directly drives the `requestTick()` loop.
* **Synchronized Narrative Beats:** The 5 text moments are bound to normalized progress:
  * `0.05 - 0.18`: *Beverly Hills. Where the ritual begins.*
  * `0.28 - 0.40`: *Âme de Vue — our signature scent, sealed within.*
